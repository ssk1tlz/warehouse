📥 УСТАНОВКА
────────────────────────────────────────────────────────────────
1. Скачайте установщик WarehouseSetup-X.Y.Z.exe со страницы
   релизов проекта:
   https://github.com/ssk1tlz/warehouse/releases

2. Запустите скачанный файл и следуйте подсказкам мастера
   установки. По желанию можно отметить галочки:
   • "Запускать при входе в Windows" - программа будет сама
     запускаться при включении компьютера
   • "Открыть порт 8765 в брандмауэре (нужно для подключения
     телефона по сети)" - отмечайте, только если к складу
     будет подключаться мобильное приложение сотрудника

3. Windows может показать синее окно "Windows защитила ваш
   компьютер". Это НЕ вирус - так Windows предупреждает про
   любую программу без платного сертификата подписи, а такой
   сертификат стоит отдельных денег и на работу программы не
   влияет. Чтобы продолжить установку: нажмите "Подробнее",
   затем "Выполнить в любом случае".

4. Программа установится в папку Program Files, на рабочем
   столе появится ярлык "Склад IT-техники". Все данные (база,
   резервные копии) хранятся отдельно от программы, в папке
   C:\ProgramData\Warehouse, и НЕ удаляются, если программу
   потом удалить через "Установка и удаление программ".

Чтобы обновиться до новой версии: скачайте новый установщик с
той же страницы релизов и запустите его. Он заменит программу,
данные при этом не пострадают.


🚀 ЗАПУСК ПРИЛОЖЕНИЯ
────────────────────────────────────────────────────────────────
Дважды кликните по ярлыку "Склад IT-техники"
(на рабочем столе или в меню Пуск)

   ✓ Показывает иконку в трее (возле часов)
   ✓ Автоматически запускает сервер
   ✓ Открывает браузер

   Когда закрываете приложение (правый клик → Выход):
   ✓ Сервер автоматически останавливается

   Меню в трее (правый клик по иконке):
   • Открыть приложение - открыть в браузере
   • Статус - показывает состояние сервера
   • Перезапустить сервер - перезапуск
   • Выход - остановка сервера и выход


🛑 ОСТАНОВКА ПРИЛОЖЕНИЯ
────────────────────────────────────────────────────────────────
Правый клик по иконке в трее → Выход


🔄 ПОВТОРНЫЙ ЗАПУСК
────────────────────────────────────────────────────────────────
При повторном запуске:
  ✓ Сервер НЕ будет запущен повторно
  ✓ Откроется только браузер с приложением
  ✓ Все данные сохранятся


🌐 АДРЕС ПРИЛОЖЕНИЯ
────────────────────────────────────────────────────────────────
http://127.0.0.1:8765/

Вы можете открыть этот адрес в любом браузере,
пока запущен сервер.


📂 РЕЗЕРВНЫЕ КОПИИ
────────────────────────────────────────────────────────────────
Автоматически сохраняются в папке:
  C:\ProgramData\Warehouse\backups\
Хранится последние 30 копий базы данных.


⚠️  ВАЖНО
────────────────────────────────────────────────────────────────
• Установленной программе больше ничего не нужно - весь код и
  файлы приложения зашиты внутрь WarehouseApp.exe
• Данные (база, резервные копии, настройки) хранятся отдельно
  от программы, в C:\ProgramData\Warehouse, и переживают и
  удаление, и переустановку программы


🛠  ДЛЯ РАЗРАБОТЧИКОВ
────────────────────────────────────────────────────────────────
Ниже - запуск без установки, прямо из исходного кода проекта.
Обычным сотрудникам склада этот раздел не нужен.

Запуск:      start_server.bat  (нужен Python 3.12+)
Остановка:   stop_server.bat

После изменения кода (server.py, app.js и т.д.):
1. Закройте приложение
2. Запустите build_exe.bat - соберёт dist\WarehouseApp_New.exe
3. Чтобы собрать установщик - installer\build_installer.bat
   (нужен установленный Inno Setup 6)

Подробности про сетевой режим, config.json и решение проблем -
в файле README.txt
