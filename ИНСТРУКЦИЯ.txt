📦 ЗАПУСК ПРИЛОЖЕНИЯ (3 способа)
────────────────────────────────────────────────────────────────

🔹 Способ 1: EXE файл (РЕКОМЕНДУЕТСЯ)
   Дважды кликните: WarehouseApp.exe
   
   ✓ Показывает иконку в трее (возле часов)
   ✓ Автоматически запускает сервер
   ✓ Открывает браузер
   ✓ Работает с актуальной версией кода
   
   Когда закрываете приложение (правый клик → Выход):
   ✓ Сервер автоматически останавливается
   
   Меню в трее (правый клик по иконке):
   • Открыть приложение - открыть в браузере
   • Статус - показывает состояние сервера
   • Перезапустить сервер - перезапуск
   • Выход - остановка сервера и выход

🔹 Способ 2: VBS файл (без консоли)
   Дважды кликните: Запустить приложение.vbs
   
   ✓ Запуск без показа консоли
   ✓ Проверяет, не запущен ли уже сервер

🔹 Способ 3: BAT файл (с консолью)
   Дважды кликните: start_server.bat
   
   ✓ Запуск с показом консоли
   ✓ Проверяет, не запущен ли уже сервер


🛑 ОСТАНОВКА ПРИЛОЖЕНИЯ
────────────────────────────────────────────────────────────────
• Если запущен WarehouseApp.exe:
  Правый клик по иконке в трее → Выход

• Если запущен через bat/vbs:
  Дважды кликните: stop_server.bat
  Или закройте окно консоли "Warehouse Server"


🔄 ПОВТОРНЫЙ ЗАПУСК
────────────────────────────────────────────────────────────────
При повторном запуске:
  ✓ Сервер НЕ будет запущен повторно
  ✓ Откроется только браузер с приложением
  ✓ Все данные сохранятся


🌐 АДРЕС ПРИЛОЖЕНИЯ
────────────────────────────────────────────────────────────────
http://127.0.0.1:8765/

Вы можете открыть этот адрес в любом браузере,
пока запущен сервер.


⚙️  ОБНОВЛЕНИЕ EXE ФАЙЛА
────────────────────────────────────────────────────────────────
Если вы изменили код (server.py, app.js и т.д.):

1. Закройте WarehouseApp.exe (Выход из трея)
2. Запустите: build_exe.bat
3. Дождитесь завершения компиляции
4. Новый файл будет в: dist\WarehouseApp_New.exe
5. Старый файл будет переименован в WarehouseApp_OLD.exe


📂 РЕЗЕРВНЫЕ КОПИИ
────────────────────────────────────────────────────────────────
Автоматически сохраняются в папке: backups\
Хранится последние 30 копий базы данных.


⚠️  ВАЖНО
────────────────────────────────────────────────────────────────
• WarehouseApp.exe теперь работает с актуальной версией!
• Не нужно пересобирать exe при каждом изменении кода
• Exe файл только запускает сервер, код берется из файлов
