  СКЛАД IT-ТЕХНИКИ - Инструкция по использованию
═══════════════════════════════════════════════════════════════

📥 УСТАНОВКА
────────────────────────────────────────────────────────────────
1. Скачайте установщик WarehouseSetup-X.Y.Z.exe со страницы
   релизов проекта:
     https://github.com/ssk1tlz/warehouse/releases

2. Запустите скачанный файл и пройдите мастер установки.
   По желанию можно отметить галочки:
     • «Запускать при входе в Windows» — приложение будет само
       запускаться при включении компьютера
     • «Открыть порт 8765 в брандмауэре (нужно для подключения
       телефона по сети)» — отмечайте, только если к серверу
       будет подключаться мобильное приложение сотрудника
       (подробнее — в разделе «СЕТЕВОЙ РЕЖИМ» ниже)

3. Windows может показать синее окно «Windows защитила ваш
   компьютер». Это НЕ вирус — так Windows предупреждает про
   любую программу без платного сертификата подписи (такой
   сертификат стоит отдельных денег и на работу программы не
   влияет). Чтобы продолжить: нажмите «Подробнее», затем
   «Выполнить в любом случае».

4. Программа установится в Program Files, на рабочем столе
   появится ярлык «Склад IT-техники». Все данные (база,
   резервные копии, настройки) хранятся отдельно от программы,
   в папке C:\ProgramData\Warehouse, и НЕ удаляются, если
   программу потом удалить через «Установка и удаление программ».

Обновление: скачайте новый установщик с той же страницы релизов
и запустите его — он заменит программу поверх старой версии,
данные не пострадают.


📦 ЗАПУСК ПРИЛОЖЕНИЯ
────────────────────────────────────────────────────────────────
  ► Дважды кликните на ярлык «Склад IT-техники»
    (на рабочем столе или в меню Пуск)

  • В системном трее появится иконка приложения
  • Сервер запустится автоматически, откроется браузер
  • Повторный запуск НЕ создаст второй экземпляр —
    просто откроется новая вкладка браузера

Запуск без установки, из исходного кода — в разделе
«ДЛЯ РАЗРАБОТЧИКОВ» ниже.


🛑 ОСТАНОВКА ПРИЛОЖЕНИЯ
────────────────────────────────────────────────────────────────
Правый клик по иконке в трее → «Выход»
  (при выходе автоматически создаётся резервная копия базы)


🔄 МЕНЮ В ТРЕЕ (правый клик по иконке)
────────────────────────────────────────────────────────────────
  • Открыть приложение  — открыть вкладку в браузере
  • Статус              — состояние сервера
  • Перезапустить сервер — перезапуск без выхода из приложения
  • Выход               — остановка сервера + резервная копия


📂 РЕЗЕРВНЫЕ КОПИИ
────────────────────────────────────────────────────────────────
Автоматические резервные копии базы данных сохраняются в:
  📁 C:\ProgramData\Warehouse\backups\

  • Копия создаётся перед каждым сохранением данных
    и при выходе из приложения
  • Хранятся последние 30 копий

Чтобы восстановить базу: остановите приложение, замените файл
C:\ProgramData\Warehouse\warehouse.db на нужный файл из папки
backups\ (переименуйте его в warehouse.db) и запустите
приложение снова.


🌐 ДОСТУП К ПРИЛОЖЕНИЮ
────────────────────────────────────────────────────────────────
После запуска приложение доступно по адресу:
  http://127.0.0.1:8765/

⚠️  Работайте с приложением в ОДНОЙ вкладке браузера.
    Если открыть несколько вкладок, при одновременном
    редактировании сервер примет только первое изменение,
    а второй вкладке предложит обновить данные.


🖥  СЕТЕВОЙ РЕЖИМ (для мобильного приложения)
────────────────────────────────────────────────────────────────
Сетевой режим нужен для того, чтобы к серверу могло подключаться
МОБИЛЬНОЕ ПРИЛОЖЕНИЕ (после привязки по QR-коду).

⚠️  Открыть приложение в браузере на другом компьютере сети
    больше нельзя. С настольной версией работают на том
    компьютере, где запущен сервер (http://127.0.0.1:8765/),
    а по сети подключается только мобильное приложение.

Если при установке отмечена галочка «Открыть порт 8765 в
брандмауэре (нужно для подключения телефона по сети)» — сетевой
режим включается сам, ничего создавать вручную не нужно: сразу
переходите к шагу 1 ниже.

Если вы не отмечали галочку при установке — запустите установщик
ещё раз и отметьте её (он обновит программу поверх текущей
версии, данные не пострадают). Ручная правка config.json нужна,
только если вы не хотите переустанавливать программу ради
галочки, либо программа уже была установлена раньше и файл
config.json в C:\ProgramData\Warehouse уже существует — тогда
установщик его не трогает, чтобы не затереть ваши настройки. В
этом случае откройте (или создайте) config.json и пропишите:
     {
       "host": "0.0.0.0",
       "port": 8765
     }
(остальные ключи, если они там есть, не трогайте).

1. Перезапустите приложение (правый клик по иконке в трее →
   «Выход», затем запустите снова).

2. Привяжите телефон: в настольном приложении откройте раздел
   «Пользователи», создайте учётную запись для сотрудника и
   покажите ей QR-код привязки. Мобильное приложение сканирует
   его и само прописывает адрес сервера и ключ устройства.

Вернуть локальный режим: откройте config.json и верните "host"
в "127.0.0.1" (файл целиком не удаляйте — там могут быть другие
настройки), затем перезапустите приложение.

Несколько человек могут работать одновременно: если двое
сохранят изменения сразу, сервер примет первое, а второму
предложит обновить данные и повторить действие.

🔒 Доступ защищён учётными записями: нужен логин, пароль и роль
   (администратор / кладовщик / наблюдатель), а запросы с других
   устройств дополнительно подписываются ключом, который выдаётся
   при привязке по QR-коду. Просто попасть в локальную сеть, чтобы
   изменить данные, недостаточно.

⚠️  ВНИМАНИЕ: соединение идёт по HTTP без шифрования, поэтому
    сетевой режим рассчитан только на доверенную локальную сеть.
    Не открывайте порт 8765 в интернет.


⚙️  НАСТРОЙКИ (config.json)
────────────────────────────────────────────────────────────────
Файл config.json в папке C:\ProgramData\Warehouse (необязательный):
  {
    "host": "0.0.0.0",   ← "127.0.0.1" = только этот компьютер,
                            "0.0.0.0" = доступ по сети
                            (для мобильного приложения)
    "port": 8765         ← порт сервера
  }
Если файла нет — приложение работает только локально.
После изменения настроек перезапустите приложение.


❓ ПРОБЛЕМЫ
────────────────────────────────────────────────────────────────
Если приложение не запускается:

1. Откройте Диспетчер задач, найдите WarehouseApp.exe и
   завершите процесс (если он там есть)
2. Подождите 5 секунд
3. Запустите приложение снова (ярлык «Склад IT-техники»)

Если проблема сохраняется, проверьте:
  • Не занят ли порт 8765 другим приложением
  • Есть ли права на запись в папку C:\ProgramData\Warehouse
  • Не остался ли файл .warehouse_app.lock в этой же папке
    (можно удалить, если приложение точно не запущено)


🛠  ДЛЯ РАЗРАБОТЧИКОВ
────────────────────────────────────────────────────────────────
Ниже — запуск без установки, прямо из исходного кода проекта.
Обычным пользователям склада этот раздел не нужен.

Запуск и остановка:
  ► start_server.bat — нужен Python 3.12+
    (пакеты — из requirements.txt)
  ► stop_server.bat — остановить сервер, запущенный так

Пересборка EXE:
После изменения кода (server.py, app.js, index.html и т.д.)
пересоберите exe-файл:
  ► rebuild_and_replace.bat, либо build_exe.bat
Подробности — в файле КАК_ПЕРЕСОБРАТЬ.txt

Сборка установщика:
  ► installer\build_installer.bat
    (нужен установленный Inno Setup 6)
Готовый файл появится в installer\output\

Сетевой режим из исходников:
  ► setup_lan.bat (от имени администратора) открывает порт 8765
    в брандмауэре и включает host "0.0.0.0" в config.json
  ► setup_local.bat (от имени администратора) закрывает порт
    и возвращает host в "127.0.0.1" в config.json
  ► add_autostart.bat добавляет ярлык в папку автозагрузки —
    рассчитан на копию WarehouseApp.exe рядом с bat-файлами;
    для программы, поставленной через установщик, вместо этого
    используйте галочку «Запускать при входе в Windows»
  Оба скрипта правят config.json в C:\ProgramData\Warehouse —
  именно там его всегда читает приложение, независимо от способа
  запуска (см. раздел «НАСТРОЙКИ» выше). Для правки нужен Python
  в PATH — без него скрипты выведут ошибку и ничего не изменят.

Если приложение не запускается (режим из исходников):
1. Запустите stop_server.bat
2. Подождите 5 секунд
3. Запустите start_server.bat снова
