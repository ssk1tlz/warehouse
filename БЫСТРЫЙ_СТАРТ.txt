🚀 ЗАПУСК
─────────────────────────────────────────────────────────────
  Дважды кликните: WarehouseApp.exe
  
  → Появится иконка в трее (возле часов)
  → Автоматически откроется браузер
  → Готово к работе!


💡 ИСПОЛЬЗОВАНИЕ
─────────────────────────────────────────────────────────────
  • Двойной клик по иконке в трее = открыть в браузере
  • Правый клик по иконке = меню:
    - Открыть приложение
    - Статус сервера
    - Перезапустить сервер
    - Выход


🛑 ОСТАНОВКА
─────────────────────────────────────────────────────────────
  Правый клик по иконке в трее → Выход
  
  → Сервер автоматически остановится
