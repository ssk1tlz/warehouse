📥 УСТАНОВКА
─────────────────────────────────────────────────────────────
  1. Скачайте WarehouseSetup-X.Y.Z.exe со страницы релизов:
     https://github.com/ssk1tlz/warehouse/releases
  2. Запустите файл, следуйте подсказкам установщика.
  3. Windows покажет окно "Windows защитила ваш компьютер" -
     это не вирус, а обычное предупреждение для программ без
     платного сертификата. Нажмите "Подробнее", затем
     "Выполнить в любом случае".
  4. По желанию отметьте:
     - "Запускать при входе в Windows"
     - "Открыть порт 8765 в брандмауэре" - только если к
       складу будет подключаться телефон сотрудника


🚀 ЗАПУСК
─────────────────────────────────────────────────────────────
  Дважды кликните по ярлыку "Склад IT-техники"
  (на рабочем столе или в меню Пуск)

  → Появится иконка в трее (возле часов)
  → Автоматически откроется браузер
  → Готово к работе!


💡 ИСПОЛЬЗОВАНИЕ
─────────────────────────────────────────────────────────────
  • Двойной клик по иконке в трее = открыть в браузере
  • Правый клик по иконке = меню:
    - Открыть приложение
    - Статус сервера
    - Перезапустить сервер
    - Выход


🛑 ОСТАНОВКА
─────────────────────────────────────────────────────────────
  Правый клик по иконке в трее → Выход

  → Сервер автоматически остановится


📌 ВАЖНО
─────────────────────────────────────────────────────────────
  ✓ Все данные хранятся в C:\ProgramData\Warehouse
  ✓ Удаление программы их не затрагивает
  ✓ При закрытии - сервер останавливается
  ✓ Можно запускать повторно - дубликатов не будет


🌐 Адрес: http://127.0.0.1:8765/
